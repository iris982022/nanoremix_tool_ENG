# Upstream preprocessing references

This directory contains historical preprocessing scripts and configuration snapshots. Use the portable command templates and configure paths, reference and sample settings for your environment. [Preprocessing commands](../docs/guide_20261104/PREPROCESSING.md)

- **RNA002** includes single-FAST5 validation, the Step4 extractor and historical job files.
- **RNA004** includes the event-feature extractor, Step6 merger, historical catalog adapters and the 9-mer level table.
- `SOURCE_MAPPING.json` describes the original files and their packaged checksums. The user guide explains the RNA004 strand and catalog restrictions. [Known limitations](../docs/KNOWN_LIMITATIONS.md)
